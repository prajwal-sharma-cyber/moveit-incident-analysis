# Security Recommendations

## 1. Vulnerability Management

Prioritise critical vulnerabilities affecting internet-facing applications.

## 2. Asset Inventory

Maintain visibility of applications, versions, owners and exposure.

## 3. Monitoring

Monitor authentication, application and network logs for unusual behaviour.

## 4. Data Protection

Minimise stored sensitive data and apply appropriate encryption and access controls.

## 5. Incident Response

Maintain an incident-response plan covering identification, containment, eradication, recovery and lessons learned.

## 6. Third-Party Risk

Assess security requirements for software vendors and managed services.

## 7. Security Testing

Perform appropriate security testing and remediation validation after major updates.
