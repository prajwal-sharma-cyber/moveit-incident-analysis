# MOVEit Transfer Incident Analysis

A cybersecurity case study analysing the 2023 MOVEit Transfer mass-exploitation incident from an information-security and risk-management perspective.

## Objectives

- Understand the security incident and attack path.
- Identify relevant vulnerability and exposure factors.
- Assess business and information-security impact.
- Discuss incident response and containment.
- Recommend preventative controls.

## Analysis Areas

- Vulnerability management
- Web application security
- Data confidentiality
- Third-party/file-transfer risk
- Incident response
- Patch management
- Security monitoring
- Risk treatment

## Key Learning Outcome

The purpose of this project is not to reproduce an exploit. It is to demonstrate how a cybersecurity professional can analyse a public incident, identify security weaknesses and translate technical findings into risk and control recommendations.
